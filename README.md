## Description

The Personal Task Manager is a Laravel-based web application that allows users to manage personal tasks. Users can add, view, edit, delete, and update the status of their tasks.

## Database Fields

The tasks table contains:

- id
- task_name
- description
- status
- due_date
- created_at
- updated_at
